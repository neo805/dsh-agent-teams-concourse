# Contributing

This is a personal hobby project maintained by the producer (`@neo805`). It is published
for sharing, with no commitment to external maintenance or support.

- **Issues are not enabled.**
- **Pull requests are not accepted.**
- You are welcome to fork the repository and evolve it under the MIT licence.
- Before using the plugin in production, review the documented limits and evaluate it in
  your own profile.

See [`README.md`](README.md) for the current state and [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md)
for known residue.
