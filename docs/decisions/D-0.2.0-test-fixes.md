## 设计取舍

- **id 撞号**：选择「计数器播种 + 撞号跳过」而不是改 uuid 或加时间戳——id 是
  用户可见、`team_status` 回显的键，保持 `concourse-N` 可读性；撞号跳过的兜底
  使手工命名（如 `concourse-abc`）不破坏自动生成。
- **未知字段**：zod 默认 strip，静默丢字段比报错更危险；扫描放在 parse 之前，
  保证「笔误」与「缺必填」同时呈现。
- **effort 别名**：别名表是显式白名单，未知名称仍按 default 位次兜底；rationale
  会注明「原生档位 X 按 Y 参与比较」，不隐藏变换。
